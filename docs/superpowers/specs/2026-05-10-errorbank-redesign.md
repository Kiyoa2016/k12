# 错题库重设计 — 双入口班级/知识点看板

> **设计 Goal:** 将 PC 端错题库从"知识点→班级→学生"单路径改为"班级看板"和"知识点看板"双页签并存，满足老师日常班级管理和学科专项分析两种场景。

## 数据流向

```
        班级看板                          知识点看板
    ┌──────────┐                     ┌──────────┐
    │ 班级列表 │                     │ 知识点列表│
    └────┬─────┘                     └────┬─────┘
         ↓                                ↓
    ┌──────────┐                     ┌──────────┐
    │班级·知识 │                     │知识点·班 │
    │点掌握情况│                     │级分布    │
    └────┬─────┘                     └────┬─────┘
         ↓                                ↓
    ┌──────────────────────────────────────┐
    │        学生错题明细（共用）           │
    └──────────────────────────────────────┘
    ↓
   智能组卷（基于当前知识点+班级）
```

## 页签一：班级看板

### 第一层 — 班级列表
- 按年级分组展示老师所教班级
- 每张班级卡片：班级名 + 薄弱知识点数 + 整体错误率（❤ >35% / 💛 20-35% / 💚 <20%）
- 错误率进度条
- 点击卡片进入第二层

### 第二层 — 班级知识点掌握情况
- 顶部：班级整体指标（正确率、薄弱知识点数、总错题数）
- 知识点列表按错误率降序，显示：前置标记（✕需重点关注/△需加强/○良好）、知识点名、错误率、出错人数、进度条
- 底部"智能组卷"按钮

### 第三层 — 学生错题明细（与知识点看板共用）
- 按出错次数降序排列
- 学生卡片：头像 + 姓名 + 错题数 + 近期具体错题标签
- 底部"智能组卷"按钮

## 页签二：知识点看板

### 第一层 — 知识点列表
- 全学科知识点按错误率降序排列
- 每项展示：学科标签、知识点名、错误率、涉及班级数、错题总数

### 第二层 — 涉及班级分布
- 当前知识点下各班级的错误率对比
- 班级卡片：班名、错误率、出错人数、进度条
- 点击班级进入第三层（学生错题明细，共用视图）

### 第三层 — 学生错题明细
- 与班级看板第三层共用同一视图

## 视觉规范
- 遵循现有 PC 视觉语言：`max-w-6xl mx-auto px-6 lg:px-8`、`bg-white rounded-xl p-5 border border-gray-100`
- 顶部 Header 使用 `bg-white/80 backdrop-blur-lg border-b border-blue-50/50`
- 页签切换沿用 ErrorBank 现有风格
- 卡片网格：`grid grid-cols-1 lg:grid-cols-2 xl:grid-cols-3 gap-3`
